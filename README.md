# 🏋️ FitZone Gym Website

FitZone Gym Website is a responsive fitness website developed using **HTML, CSS, JavaScript, Node.js, and Express.js**. The project provides a modern and user-friendly interface where users can explore gym services, calculate their Body Mass Index (BMI), and contact the gym through an interactive contact form.

## 🚀 Features

- Responsive and Modern UI
- Hero Section
- Gym Services Section
- BMI Calculator
- Contact Form
- Mobile-Friendly Design
- Backend Integration with Express.js
- Clean and Simple User Interface

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- CORS

## ▶️ How to Run

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

Open `index.html` using **Live Server** in VS Code or any modern web browser.
