# 🏋️ FitZone Gym Website

A responsive Gym Website built using **HTML, CSS, JavaScript, Node.js, and Express.js**. The project features a modern user interface, a BMI calculator, and a contact form with backend integration.

## 🚀 Features

- Responsive Navigation Bar
- Hero Section
- BMI Calculator
- Contact Form
- Modern Dark UI
- Mobile Responsive Design
- Express.js Backend
- Easy to Customize

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- CORS

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/FitZone-Gym.git
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Start the Backend

```bash
node server.js
```

### Run the Frontend

Open the `frontend` folder and run **index.html** using **Live Server** in VS Code.
